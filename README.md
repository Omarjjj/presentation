# السلامة الرقمية للصحفيين في عصر الـAI

عرض تقديمي تفاعلي بالعربية (19 شريحة) — الحقيبة الرقمية لنجاة الصحفيين.

## التشغيل

افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا:

```bash
npm start
```

ثم افتح: **http://localhost:5500**

## التنقل

- **السهم الأيسر** / **مسافة** / **Page Down**: الشريحة التالية
- **السهم الأيمن** / **Page Up**: الشريحة السابقة
- **Home** / **End**: أول وآخر شريحة
- النقاط على اليسار: الانتقال المباشر
- زر **⛶**: ملء الشاشة (وضع عرض PowerPoint)

## الطباعة

يمكن طباعة الشرائح من المتصفح (كل شريحة صفحة منفصلة).
